# 小喆的博客

个人博客，记录技术学习和日常。

## 技术栈

- [Astro](https://astro.build)
- [Pure Theme](https://github.com/cworld1/astro-theme-pure)
- 部署在 [Vercel](https://vercel.com)

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 写文章

在 `src/content/blog/` 下新建 `.md` 文件，格式参考已有文章。
